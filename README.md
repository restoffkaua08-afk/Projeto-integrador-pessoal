# `> PROJECT.OVERVIEW`

O ESMERALD é um hub competitivo criado para organizar informações e experiências relacionadas a Warzone. O projeto combina uma interface React com uma API PHP e persistência MySQL, executadas em ambiente local pelo XAMPP.

<br>

# `> CORE.TECH_STACK`

<div align="center">

<img src="https://skillicons.dev/icons?i=react,js,php,mysql,vite,git,github&theme=dark" alt="Tecnologias utilizadas"/>

</div>

**Stack principal:** React • Vite • PHP • MySQL

<br>

# `> SYSTEM.FEATURES`

- interface web em React;
- integração do frontend com API;
- backend em PHP;
- persistência MySQL;
- scripts SQL de criação do banco;
- script PowerShell para inicialização local;

<br>

# `> PROJECT.STRUCTURE`

```text
webEsmerald-Plataform/  # aplicação React e API PHP
database/               # scripts SQL
index.php               # implementação PHP preservada
rodar.ps1               # inicialização local
```

A árvore acima representa os componentes principais encontrados no repositório.

<br>

# `> GETTING.STARTED`

1. Instale Node.js, XAMPP e MySQL.
2. Clone o repositório dentro de `C:\\xampp\\htdocs`.
3. Execute `./rodar.ps1` ou inicialize frontend e API separadamente.
